## Ваш прогресс сразу после подключения

**Прогресс по каждой игре загружается сразу.** Больше никакого «откройте для проверки»: вставьте ссылку, и вся библиотека покажет полученные достижения и проценты. Библиотека на 300 игр — это три запроса вместо трёхсот.

**Установленные игры в боковом меню.** Achievement Hunter находит игры Steam, установленные на вашем ПК, и показывает их под *Библиотекой* вместе с прогрессом. Один клик — и вы в игре.

**Мелкие изменения**
- Обновление библиотеки обновляет и прогресс.
- Прогресс перезагружается только для игр, в которые вы играли после последней проверки.
