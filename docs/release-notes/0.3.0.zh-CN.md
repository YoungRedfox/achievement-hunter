## 现已支持 10 种语言，并完全开源

**在开始界面直接选择语言。** English、简体中文、Русский、Español、Português (Brasil)、Deutsch、Français、日本語、한국어 和 Polski。成就名称和指南会随应用语言一起切换。

**基于 GPL-3.0 开源。** 阅读代码、自行构建、提出修改：[YoungRedfox/achievement-hunter](https://github.com/YoungRedfox/achievement-hunter)。

**其他小改动**
- AI 指南服务繁忙时提示更清楚，并会自动重试。
- 默认语言改为英语。
