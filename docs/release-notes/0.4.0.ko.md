## 연결하자마자 진행 상황 확인

**모든 게임의 진행 상황이 바로 불러와집니다.** 이제 "열어서 확인"은 없습니다. 링크만 붙여 넣으면 라이브러리 전체에 달성 개수와 퍼센트가 표시됩니다. 게임 300개도 요청 300번이 아니라 3번이면 됩니다.

**사이드바에 설치된 게임 표시.** PC에 설치된 Steam 게임을 찾아 *라이브러리* 아래에 진행률과 함께 보여 줍니다. 클릭 한 번이면 바로 이동합니다.

**작은 변경 사항**
- 라이브러리를 새로고침하면 진행 상황도 함께 새로고침됩니다.
- 마지막 확인 이후 플레이한 게임만 진행 상황을 다시 불러옵니다.
