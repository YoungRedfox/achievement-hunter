## Now in 10 languages, and fully open source

**Pick your language right on the start screen.** English, 简体中文, Русский, Español, Português (Brasil), Deutsch, Français, 日本語, 한국어 and Polski. Achievement names and guides switch along with the app.

**Open source under GPL-3.0.** Read the code, build it yourself, suggest changes: [YoungRedfox/achievement-hunter](https://github.com/YoungRedfox/achievement-hunter).

**Smaller things**
- Clearer message when the AI guide service is busy, with an automatic retry.
- English is now the default language.
