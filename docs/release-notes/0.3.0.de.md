## Jetzt in 10 Sprachen und komplett Open Source

**Wähle deine Sprache direkt auf dem Startbildschirm.** English, 简体中文, Русский, Español, Português (Brasil), Deutsch, Français, 日本語, 한국어 und Polski. Namen der Errungenschaften und Guides wechseln mit.

**Open Source unter GPL-3.0.** Code lesen, selbst bauen, Änderungen vorschlagen: [YoungRedfox/achievement-hunter](https://github.com/YoungRedfox/achievement-hunter).

**Kleinigkeiten**
- Klarere Meldung, wenn der KI-Dienst ausgelastet ist, mit automatischem neuem Versuch.
- Englisch ist jetzt die Standardsprache.
