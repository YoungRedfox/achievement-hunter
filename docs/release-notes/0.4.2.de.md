## Nach jedem Update siehst du, was neu ist

**Ein „Neu“-Fenster nach jedem Update.** Beim ersten Start einer neuen Version bekommst du eine kurze Übersicht der Änderungen in deiner Sprache. Ein paar Updates übersprungen? Du siehst alle, die neueste zuerst.

**Jederzeit nachlesen.** Unter Einstellungen → Über gibt es jetzt den Button **Was ist neu**.

**Einstellungen jetzt unter deinem Avatar.** Ein Klick auf Avatar oder Namen öffnet dein Steam-Profil.
