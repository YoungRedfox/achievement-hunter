## Agora em 10 idiomas e totalmente open source

**Escolha seu idioma direto na tela inicial.** English, 简体中文, Русский, Español, Português (Brasil), Deutsch, Français, 日本語, 한국어 e Polski. Os nomes das conquistas e os guias mudam junto com o app.

**Open source sob GPL-3.0.** Leia o código, compile você mesmo, sugira mudanças: [YoungRedfox/achievement-hunter](https://github.com/YoungRedfox/achievement-hunter).

**Mudanças menores**
- Mensagem mais clara quando o serviço de guias com IA está sobrecarregado, com nova tentativa automática.
- O inglês agora é o idioma padrão.
