## Désormais en 10 langues et entièrement open source

**Choisis ta langue dès l’écran d’accueil.** English, 简体中文, Русский, Español, Português (Brasil), Deutsch, Français, 日本語, 한국어 et Polski. Les noms des succès et les guides suivent la langue de l’app.

**Open source sous licence GPL-3.0.** Lis le code, compile-le toi-même, propose des changements : [YoungRedfox/achievement-hunter](https://github.com/YoungRedfox/achievement-hunter).

**Petits changements**
- Message plus clair quand le service de guides IA est surchargé, avec une nouvelle tentative automatique.
- L’anglais est maintenant la langue par défaut.
