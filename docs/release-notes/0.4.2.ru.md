## После каждого обновления видно, что изменилось

**Окно «Что нового» после каждого обновления.** При первом запуске новой версии вы увидите краткий список изменений на своём языке. Пропустили несколько обновлений? Покажем все, начиная с самого нового.

**Можно перечитать в любой момент.** В разделе Настройки → О приложении появилась кнопка **Что нового**.

**Настройки теперь под аватаром.** Нажмите на аватар или ник, чтобы открыть профиль Steam.
