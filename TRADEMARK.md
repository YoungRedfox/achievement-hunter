# Name and logo

The source code of Achievement Hunter is licensed under GPL-3.0. The name **"Achievement Hunter"** and the logo (`build/icon.svg`, `build/icon.png`) are **not** licensed under GPL-3.0.

You are welcome to fork and modify the project. If you distribute a modified version, please:

- use a different name and logo, so users can tell it apart from the official app;
- point it to your own server (`DEFAULT_PROXY_URL` in `shared/config.ts`) — the official server and its daily limits are reserved for the official app.

Official builds are published only at https://github.com/YoungRedfox/achievement-hunter-releases.
